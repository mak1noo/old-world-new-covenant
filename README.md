# 旧界新约 v0.0.2

原创双人卡牌对战游戏的桌面网页版。支持两档 AI 和房间码联机。建议使用桌面 Chrome 或 Edge，视口至少 1280 × 800。

## 启动

发布包文件名为 `旧界新约v0.0.2.zip`，需要 Node.js 20 或更新版本。

完整解压游戏包后，Windows 双击 `点击启动游戏.cmd`，macOS 或 Linux 在解压目录运行 `./start-game.sh`。脚本自动打开浏览器。关闭启动窗口或按 Ctrl+C 退出。

下载包已包含客户端和服务端构建文件，启动只需 Node.js。

### 开发启动

源码开发需要与 Node.js 版本兼容的 pnpm。开发验证使用 Node.js 24、pnpm 11。

```sh
pnpm install
pnpm build
pnpm start
```

打开 http://localhost:8080。开发时也可运行 `pnpm dev`，客户端由 Vite 提供，WebSocket 转发到本地 8080。

## 公网联机与观战

1. 房主启动 SakuraFrp 原有隧道，然后双击 `樱花联机开服.cmd`。游戏服务监听 `127.0.0.1:25565`，隧道须能转发该端口及 `/ws` 的 WebSocket 连接。
2. 房主在游戏内选择「对战联机 → 创建房间」，把 SakuraFrp 公网地址和六位房间码交给其他玩家。
3. 加入者打开该公网地址，输入房间码，再选择「战斗席」或「观战席」。房间有两个战斗席，最多 16 个观战席。观众可在开战前改坐空闲战斗席。
4. 战斗席临时断开时，房间暂停并保留席位 45 秒。保持原网页打开即可自动尝试重连。主动退出、断线超时或关闭服务端会结束在线房间。

准备阶段可以点击已上阵的从者，再点另一名从者交换站位，也可以直接拖拽换位。准备完成后，在对方尚未准备时可以取消。开战后用「本场投降」按战败结算当前场次。

## 测试

```sh
pnpm test
```

测试包括 500 局随机对战，运行约 1–2 分钟。结果摘要见 `TEST-REPORT.md`。

## 目录

- `data/cards.json` 存放运行时卡牌数值、配方、技能和常量。
- `packages/shared` 实现共享规则、合法操作、视角投影和测试。
- `packages/server` 实现 HTTP、WebSocket 房间与两档 AI。
- `packages/client` 实现 React 页面和操作界面。
- `DECISIONS.md` 记录作者最终确认的裁定。
- `HANDOFF.md` 记录里程碑与继续开发所需信息。

## 版本范围

战场使用原创修道院背景与 CSS 卡面。当前卡牌数据包含种族，缺少阵营归属的卡统一显示为「未指定阵营」。锁定 a 位和翻面状态按规格预留，特殊融合、服务重启后恢复对局、移动端以及面向玩家的回放不在本版本范围内。
